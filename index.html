图像编辑能力，
一行脚本即可调用

Photoedits 是一个只在浏览器里运行的图像编辑 API。它把 PNG/APNG 压缩、TIFF/EXIF/RAW 解析、ZIP 打包、字体解析、神经网络推理五大引擎聚合到一个全局对象里，按需加载，无需服务器，图片永不离开用户设备。

01快速开始

三步即可在任意网页中使用。

第 1 步：引入脚本

<script src="https://photoedits.leleleling.site/api/api.js"></script>

脚本会同步创建全局对象 Photoedits。底层引擎默认不加载，直到你第一次调用相关方法——这就是为什么它很轻。

第 2 步：调用方法

// 读取一张图片，缩放后导出为 PNG Blob，再下载
const small = await Photoedits.canvas.resize('photo.jpg', 800, 600);
const blob  = await Photoedits.canvas.toBlob(small, 'image/png');
Photoedits.utils.download(blob, 'small.png');

第 3 步：按需预加载（可选）

// 提前把所有引擎加载好，避免首次调用时的等待
await Photoedits.ready();

// 或者只加载其中一个
await Photoedits.use('png');   // png | tiff | zip | font | nn
Photoedits.isLoaded('png');       // => true
所有异步方法都返回标准 Promise，可以用 await 或 .then()。同步工具（如 utils.download）会在文档中用 sync 标注。

02核心概念

按需加载

首次调用某模块方法时，API 会自动从 /api/libs/ 加载对应脚本并缓存。重复调用不会重复下载。

纯前端

没有后端、没有接口、没有账号。所有计算在用户浏览器内完成，图片数据不会上传。

统一 Promise

涉及加载或图像解码的方法一律异步返回，错误通过 reject 抛出，可用 try/catch 捕获。

原始对象逃生口

需要底层库完整能力时，用 Photoedits.raw.UPNG 等直接访问（需先 use），不被封装限制。

全局对象结构

Photoedits
├── version          // '1.0.0'
├── baseUrl          // 自动探测得到的 API 目录
├── modules          // ['png','tiff','zip','font','nn']
├── use(name)        // 预加载指定模块
├── ready()          // 预加载全部模块
├── isLoaded(name)   // 查询加载状态
├── raw              // {UPNG, UTIF, UZIP, Typr, UNN}
├── utils            // 通用工具
├── canvas           // Canvas 图像处理
├── png              // UPNG 封装 + 高层方法
├── tiff             // UTIF 封装 + 高层方法
├── zip              // UZIP 封装
├── font             // Typr 封装 + 高层方法
├── nn               // UNN 封装
└── config           // baseUrl() / timeout()

03工具 Photoedits.utils

数据类型转换与下载，无需加载任何底层库。

utils.toArrayBuffer(input)asyncPromise<ArrayBuffer>

把 ArrayBuffer、TypedArray、Blob、File 统一转成 ArrayBuffer。

utils.toBlob(input, type?)asyncPromise<Blob>

把 ArrayBuffer / Blob / dataURL 统一转成 Blob。type 为 MIME 类型。

utils.arrayBufferToBlob(buffer, type?)syncBlob

ArrayBuffer 转 Blob。默认 MIME 为 application/octet-stream。

utils.blobToDataURL(blob)asyncPromise<string>

Blob 转 dataURL 字符串。

utils.dataURLToBlob(dataURL)syncBlob

dataURL 字符串转 Blob。

utils.download(blob, filename?)syncstring

触发浏览器下载。接受 Blob 或 ArrayBuffer。

utils.bytesToBase64(bytes)syncstring

Uint8Array / ArrayBuffer 转 Base64 字符串。

utils.base64ToBytes(b64)syncUint8Array

Base64 字符串转 Uint8Array。

const buf   = await Photoedits.utils.toArrayBuffer(file);
const b64   = Photoedits.utils.bytesToBase64(new Uint8Array(buf));
Photoedits.utils.download(buf, 'copy.bin');

04Canvas 图像处理 Photoedits.canvas

基于原生 Canvas 2D，不依赖底层库，覆盖常用的裁剪、缩放、旋转、滤镜等操作。

canvas.load(src, crossOrigin?)asyncPromise<HTMLImageElement>

加载图片。crossOrigin 默认 'anonymous'，传 false 可关闭（同源图片建议关闭以避免额外请求头）。

canvas.toCanvas(source)asyncPromise<HTMLCanvasElement>

把图片 URL、Blob、File、<img>、<canvas> 统一转成 canvas。

canvas.create(w, h)syncHTMLCanvasElement

创建指定尺寸的空白 canvas。

canvas.toBlob(source, type?, quality?)asyncPromise<Blob>

导出为 Blob。type 如 'image/jpeg'，quality 为 0–1。

canvas.toDataURL(source, type?, quality?)asyncPromise<string>

导出为 dataURL 字符串。

canvas.getImageData(source)asyncPromise<ImageData>

获取像素数据。

canvas.putImageData(imageData)syncHTMLCanvasElement

把 ImageData 绘制到新 canvas。

canvas.resize(source, width, height, opts?)asyncPromise<canvas>

高质量缩放。opts.smooth=false 关闭平滑（像素风），opts.quality 取 'low'|'medium'|'high'。

canvas.crop(source, x, y, width, height)asyncPromise<canvas>

按矩形区域裁剪。

canvas.rotate(source, degrees, bg?)asyncPromise<canvas>

任意角度旋转，canvas 会自动扩展以容纳完整图像。bg 为填充色。

canvas.flip(source, direction)asyncPromise<canvas>

翻转。direction 取 'x'|'horizontal' 或 'y'|'vertical'。

canvas.filter(source, cssFilter)asyncPromise<canvas>

应用 CSS filter 字符串：'grayscale(1)'、'sepia(0.5)'、'blur(3px)'、'brightness(1.2)'、'contrast(1.3)'、'saturate(2)'、'hue-rotate(90deg)' 等。

canvas.watermark(source, text, opts?)asyncPromise<canvas>

叠加文字水印。opts 支持 font、color、align、baseline、x、y。

// 裁剪 + 旋转 + 黑白 + 水印流水线
let img = await Photoedits.canvas.crop('photo.jpg', 0, 0, 1200, 800);
img = await Photoedits.canvas.rotate(img, 90);
img = await Photoedits.canvas.filter(img, 'grayscale(1) contrast(1.15)');
img = await Photoedits.canvas.watermark(img, '© Photoedits', {color:'rgba(255,255,255,.8)'});
Photoedits.utils.download(await Photoedits.canvas.toBlob(img, 'image/jpeg', .9), 'result.jpg');

05PNG / APNG Photoedits.png

基于 UPNG.js。支持无损 / 有损压缩、APNG 动图编解码、像素量化。首次调用自动加载 UPNG.js。

UPNG 使用 RGBA 像素数据（每像素 4 字节）。编码前请准备好 ArrayBuffer 形式的像素数据。
png.encode(imgs, w, h, cnum?, dels?)asyncPromise<ArrayBuffer>

编码 PNG / APNG。imgs 为 RGBA ArrayBuffer 数组（单帧 PNG 传一个元素即 APNG 的「单帧」）。

  • w,h：图像宽高
  • cnum：颜色数，0=无损，256=有损压缩（类似 TinyPNG）
  • dels：每帧延迟毫秒数组（多帧时必填）
png.encodeLL(imgs, w, h, cc, ac, depth, dels?)asyncPromise<ArrayBuffer>

底层编码。cc=颜色通道数(1/3)，ac=alpha 通道(0/1)，depth=位深(1/2/4/8/16)。用于 16 位色等特殊场景。

png.decode(buffer)asyncPromise<object>

解码 PNG / APNG，返回含 width、height、frames、tabs 等字段的对象。

png.toRGBA8(decoded)asyncPromise<ArrayBuffer[]>

把 decode() 的结果转成 RGBA ArrayBuffer 数组（每帧一个）。

png.quantize(rgba, w, h, cnum, opts?)asyncPromise<object>

颜色量化，用 K-D 树把图片压缩到指定颜色数。

png.minify(buffer, colors=256, dels?)asyncPromise<ArrayBuffer>

高层方法：解码 → 转 RGBA → 重新编码，一步完成有损压缩。适合减小 PNG 体积。

png.fromCanvas(source, colors=0, dels?)asyncPromise<ArrayBuffer>

高层方法：直接把图片/canvas 编码成 PNG ArrayBuffer。

png.toBlob(source, colors=0, dels?)asyncPromise<Blob>

高层方法：直接输出 PNG Blob，可直接下载。

// 例 1：把任意图片压成更小的 PNG
const buf = await Photoedits.utils.toArrayBuffer(file);
const small = await Photoedits.png.minify(buf, 256);
Photoedits.utils.download(small, 'minified.png');

// 例 2：canvas 直接转 PNG 下载
const blob = await Photoedits.png.toBlob('photo.jpg');
Photoedits.utils.download(blob, 'converted.png');

// 例 3：合成 2 帧 APNG
const f1 = await Photoedits.canvas.getImageData('a.png');
const f2 = await Photoedits.canvas.getImageData('b.png');
const apng = await Photoedits.png.encode([f1.data.buffer, f2.data.buffer], f1.width, f1.height, 0, [500, 500]);

06TIFF / EXIF Photoedits.tiff

基于 UTIF.js。解码 TIFF、相机 RAW 内嵌预览，读取 EXIF 元数据，也可编码 TIFF。

tiff.decode(buffer, prm?)asyncPromise<IFD[]>

解析 TIFF / EXIF 结构，返回 IFD（图像文件目录）数组。每个 IFD 的键为 t256（宽）、t257（高）、t271（相机厂商）等标签。prm 可传 {parseMN:true, debug:false}。

tiff.decodeImage(buffer, ifd, ifds?)asyncPromise<void>

解压指定 IFD 的像素数据，会向 ifd 写入 width、height、data。

tiff.toRGBA8(ifd, scale?)asyncPromise<Uint8Array>

把已解码的 IFD 转成 8 位 RGBA 像素数组。

tiff.encodeImage(rgba, w, h, metadata?)asyncPromise<ArrayBuffer>

把 RGBA 像素编码为 TIFF。metadata 可写入 EXIF 标签。

tiff.encode(ifds)asyncPromise<ArrayBuffer>

把 IFD 数组编码为完整 TIFF 文件。

tiff.replaceIMG(imgs)asyncPromise<void>

把页面中 <img> 的 TIFF/RAW 占位替换为解码后的 canvas。

tiff.bufferToURI(buffer)asyncPromise<string>

ArrayBuffer 转 data:image/... URI。

tiff.toCanvas(buffer, index=0, opts?)asyncPromise<canvas>

高层方法：解码 → 转 RGBA → 生成 canvas，一步到位。opts.decodeOptions 传给 decode，opts.scale 传给 toRGBA8。

// 例 1：读取 EXIF 相机信息
const buf  = await Photoedits.utils.toArrayBuffer(file);
const ifds = await Photoedits.tiff.decode(buf);
console.log(ifds[0]['t271'], ifds[0]['t272']); // 厂商 / 型号

// 例 2：TIFF 转 canvas 再导出 PNG
const c   = await Photoedits.tiff.toCanvas(buf);
const png = await Photoedits.png.toBlob(c);
Photoedits.utils.download(png, 'converted.png');
RAW 文件（.cr2/.nef/.arw）只能解码其中的传感器数据与 JPG 预览，UTIF 不负责把传感器数据冲洗成可视图像。

07ZIP 打包 / 解包 Photoedits.zip

基于 UZIP.js。比 pako 更快、更小的 ZIP 实现，适合打包工程文件或批量图片。

zip.encode(obj, noCmpr?)asyncPromise<ArrayBuffer>

把 {文件名: Uint8Array} 对象打包成 ZIP ArrayBuffer。noCmpr=true 可跳过压缩。

zip.decode(buffer, onlyNames?)asyncPromise<object>

解包 ZIP，返回 {文件名: Uint8Array}。onlyNames=true 时只返回文件名。

zip.parse(buffer, onlyNames?)asyncPromise<object>

decode 的别名。

zip.deflate(data, opts?) / inflate(data)asyncPromise<Uint8Array>

原始 DEFLATE 压缩 / 解压。opts.level 控制压缩级别。

zip.deflateRaw(...) / inflateRaw(...)asyncPromise<Uint8Array>

裸 DEFLATE（无 zlib 头尾）。

// 打包多张图片
const files = {
  'a.png': new Uint8Array(await Photoedits.utils.toArrayBuffer(fileA)),
  'b.png': new Uint8Array(await Photoedits.utils.toArrayBuffer(fileB))
};
const zipped = await Photoedits.zip.encode(files);
Photoedits.utils.download(zipped, 'images.zip');

// 解包
const out = await Photoedits.zip.decode(zipped);
console.log(Object.keys(out)); // ['a.png','b.png']

08字体解析 Photoedits.font

基于 Typr.js。解析 TTF/OTF/TTC/WOFF 字体，实现「文字转曲」、字形轮廓提取与 SVG 路径输出。Photopea 的官方文字引擎。

font.parse(buffer)asyncPromise<Font[]>

解析字体文件，返回字体对象数组（TTC 含多个）。

font.load(buffer)asyncPromise<Font>

高层方法：解析并返回第一个字体对象。

font.codeToGlyph(f, code)asyncPromise<number>

Unicode 码点 → 字形索引。

font.glyphToPath(f, glyph)asyncPromise<Path>

字形索引 → 路径对象（含 cmds 命令与 crds 坐标）。

font.shapeToPath(f, text, prm?)asyncPromise<Path>

整段文字 → 路径对象，自动处理字距、连字、 RTL。

font.pathToSVG(path)asyncPromise<string>

路径对象 → SVG d 属性字符串。

font.svgToPath(svg)asyncPromise<Path>

SVG 元素 → 路径对象（反向转换）。

font.textToSVG(buffer, text, opts?)asyncPromise<string>

一步到位：字体文件 + 文字 → SVG 路径字符串。opts.prm 传给 shapeToPath。

font.use()asyncPromise<object>

返回 Typr.U 工具对象，可调用未封装的其他方法（shape、pathToContext、initHB 等）。

// 文字转曲：输出可直接放进 <svg> 的 path
const svgPath = await Photoedits.font.textToSVG(fontFile, 'Photoedits');
console.log(svgPath); // "M10 20 C..."

// 手动流程
const f    = await Photoedits.font.load(fontFile);
const path = await Photoedits.font.shapeToPath(f, 'ABC');
const d    = await Photoedits.font.pathToSVG(path);

09神经网络 Photoedits.nn

基于 UNN.js。纯 JavaScript 深度学习推理，比 ConvNetJS 快约 4 倍，可在浏览器本地运行轻量模型。

nn.create(topo, v)asyncPromise<Net>

创建网络。topo 为层定义数组，如 [['inpt','line',2,1,1],['full','sigm',2,1,1],['full','sigm',1,1,1]]；v 为初始随机权重范围。

nn.train(net, inputs, outputs, prm, debug?)asyncPromise<number>

训练网络，返回误差。prm 支持 {method:'sgd'|'momentum'|'adagrad'|'adadelta', batch_size:N}。

nn.run(net, input, output?)asyncPromise<number[]>

前向推理，返回输出向量。

nn.clone(net) / getError(...) / getDeltas(...)asyncPromise<any>

网络克隆、误差计算、梯度获取。

nn.weightCount(net)asyncPromise<number>

统计网络参数量。

nn.fromConvNetJS(json)asyncPromise<Net>

导入 ConvNetJS 格式的模型 JSON。

nn.fromCaffe(prototxt, model)asyncPromise<Net>

导入 Caffe 的 .prototxt 与 .caffemodel。

nn.util()asyncPromise<object>

返回 UNN.util 原始工具对象。

// 训练一个 XOR 网络
const net = await Photoedits.nn.create([
  ['inpt','line',2,1,1],
  ['full','sigm',2,1,1],
  ['full','sigm',1,1,1]
], 0.5);

await Photoedits.nn.train(net, [[0,0],[0,1],[1,0],[1,1]],
                              [[0],[1],[1],[0]],
                              {method:'adadelta', batch_size:4});
console.log(await Photoedits.nn.run(net, [1,0])); // ≈ [1]

10错误处理与配置

try {
  const img = await Photoedits.tiff.toCanvas(file);
} catch (err) {
  console.error(err.message);
  // "[Photoedits] 加载超时: .../libs/UTIF.js (20000ms)"
}
配置说明
Photoedits.config.baseUrl(url)手动指定 API 目录地址。默认自动从当前脚本 src 推断，通常无需设置。修改会清空加载缓存。
Photoedits.config.timeout(ms)设置单个库脚本加载超时，默认 20000ms。
跨域资源注意：用 canvas.load(url) 加载其他域名的图片时，对方服务器必须返回 Access-Control-Allow-Origin 头，否则 canvas 会被污染，getImageData/toBlob 会抛错。本地文件（Blob/File）不受此限制。
